## 2. Overall Description

### 2.1 Product Context

ระบบรองรับการบันทึกสิ่งของในคลัง การแจ้งของหาย การแจ้งเบาะแส การส่งหลักฐาน และการตรวจคำร้อง โดยเก็บข้อมูลให้เจ้าหน้าที่ใช้งานร่วมกันตาม FR-CLF-01 ผู้ใช้งานเข้าถึงข้อมูลตามบทบาท และข้อมูลที่เผยแพร่ต้องผ่านข้อกำหนดความเป็นส่วนตัว

ไฟล์ที่ได้รับยังไม่ระบุระบบภายนอกที่จะเชื่อมต่ออย่างชัดเจน ช่องทางแจ้งเตือน Email/App ยังเป็นคำถามใน FR-CLF-07 จึงยังไม่กำหนดบริการหรือเทคโนโลยีที่จะใช้
