### Acceptance Criteria

#### AC-01 — บันทึกรายการสิ่งของ
- Given เจ้าหน้าที่อยู่ในหน้าจัดการคลัง
- When เจ้าหน้าที่กรอกข้อมูลสิ่งของและกดบันทึก
- Then ระบบบันทึกรายการสิ่งของเข้าสู่คลังได้

#### AC-02 — ค้นหาและติดตามสถานะสิ่งของ
- Given มีรายการสิ่งของอยู่ในระบบ
- When เจ้าหน้าที่ค้นหารายการสิ่งของ
- Then ระบบแสดงรายการและสถานะปัจจุบันของสิ่งของ

#### AC-03 — แจ้งของหาย
- Given ผู้ทำของหายเปิดแบบฟอร์มแจ้งของหาย
- When กรอก **ชื่อสิ่งของ, หมวดหมู่ และสถานที่สูญหาย** แล้วส่งแบบฟอร์ม
- Then ระบบบันทึกคำร้องแจ้งของหายเพื่อใช้ในการค้นหาและจับคู่

#### AC-04 — แจ้งเบาะแสของที่พบ
- Given ผู้พบของต้องการแจ้งข้อมูล
- When กรอกข้อมูลเบาะแสและปักพิกัดสถานที่พบ
- Then ระบบบันทึกข้อมูลโดยไม่บังคับให้เปิดเผยชื่อหรือช่องทางติดต่อส่วนตัวต่อสาธารณะ

#### AC-05 — ส่งหลักฐานความเป็นเจ้าของ
- Given ผู้ทำของหายมีหลักฐานยืนยันความเป็นเจ้าของ
- When แนบไฟล์หลักฐานที่มีขนาดไม่เกิน 10MB และส่งให้เจ้าหน้าที่
- Then ระบบส่งหลักฐานผ่านช่องทางส่วนตัวและไม่แสดงหลักฐานต่อสาธารณะ

#### AC-06 — เปลี่ยนสถานะคำร้อง
- Given มีคำร้องยืนยันความเป็นเจ้าของ
- When เจ้าหน้าที่ตรวจสอบและเลือกสถานะ pending, verified, rejected หรือ returned พร้อมเหตุผล
- Then ระบบบันทึกสถานะและเหตุผลของคำร้อง

#### AC-07 — ปกปิดข้อมูลส่วนบุคคล
- Given เจ้าหน้าที่นำรายการสิ่งของไปเผยแพร่ต่อสาธารณะ
- When ระบบเตรียมข้อมูลสำหรับแสดงผล
- Then ข้อมูลส่วนบุคคล เช่น เลขบัตรประจำตัว ข้อมูลติดต่อ และภาพส่วนบุคคล จะถูกปิดบัง และภาพที่จำเป็นต้องปิดข้อมูลจะผ่านการเบลอร์ก่อนแสดง

#### AC-08 — ควบคุมสิทธิ์ตามบทบาท
- Given IT Admin มีสิทธิ์จัดการการเข้าถึงข้อมูล
- When IT Admin ตรวจสอบหรือกำหนดสิทธิ์ของบทบาท Public, Requester, Staff และ IT Admin
- Then ระบบจำกัดการเข้าถึงข้อมูลตามบทบาท และไม่แสดงหลักฐานยืนยันตัวตนแก่ผู้ที่ไม่มีสิทธิ์

## 6. Negotiation / Trade-off Notes

- เลือกทำทั้ง 7 requirements ที่มี Priority เป็น **Must** ตาม Requirement Backlog v1.0
- ใช้ข้อมูลพื้นฐานของระบบ เช่น ชื่อสิ่งของ หมวดหมู่ สถานที่สูญหาย/พบ สถานะคำร้อง และหลักฐาน เพื่อให้ User Story และ Use Case เข้าใจง่าย
- ไม่เพิ่ม requirement ที่เป็น **Should, Could หรือ Won't yet** เข้ามาในขอบเขตหลักของงานนี้
- ยังไม่กำหนดรายละเอียดเชิงเทคนิค เช่น วิธีพัฒนา AI Auto-censor หรือรายละเอียดนโยบาย Retention เพราะเป็นประเด็นที่ backlog ระบุว่ายังเป็น Open Question
