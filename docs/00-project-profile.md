## 2. Elevator Pitch

ระบบ Campus Lost and Found ช่วยให้นักศึกษา บุคลากร ผู้พบของ และเจ้าหน้าที่มีจุดศูนย์กลางในการแจ้ง ค้นหา ตรวจสอบ และส่งคืนสิ่งของที่สูญหายในมหาวิทยาลัยอย่างเป็นระบบ ระบบช่วยลดข้อมูลกระจัดกระจาย ลดความเสี่ยงจากการแอบอ้างรับของ และปกป้องข้อมูลส่วนบุคคลที่อาจติดมากับสิ่งของหรือภาพถ่าย

## 3. Scope ระดับสูง

### In Scope
- ระบบการแจ้งของหายและการแจ้งพบของ
- ระบบจัดการภาพถ่ายและคำบรรยายเพื่อความเป็นส่วนตัว
- ระบบค้นหาและจัดหมวดหมู่สิ่งของ
- กระบวนการยืนยันความเป็นเจ้าของเบื้องต้น
- ระบบจัดการสถานะสิ่งของสำหรับเจ้าหน้าที่
- ระบบแจ้งเตือนระยะเวลาจัดเก็บหรือสิ่งของตกค้าง

### Out of Scope
- ระบบติดตามพัสดุหรือการจัดส่ง
- การเชื่อมต่อระบบกล้องวงจรปิด (CCTV)
- การยืนยันตัวตนทางกฎหมายเต็มรูปแบบ
- การจัดการธุรกรรมทางการเงิน
- การขายทอดตลาดหรือประมูล
- การดำเนินการสืบสวนทางกฎหมาย
- การจัดการของหายภายนอกพื้นที่มหาวิทยาลัย

## 4. ผู้ใช้หลัก

| Role | เป้าหมายหลัก | สิ่งที่คาดว่าจะทำกับระบบ |
|---|---|---|
| ผู้ทำของหาย | ค้นหาสิ่งของที่หายได้เร็วขึ้น และยืนยันตัวตนเพื่อรับของคืนอย่างปลอดภัย | แจ้งของหาย ค้นหารายการของที่พบ ส่งหลักฐานความเป็นเจ้าของ และติดตามสถานะ |
| ผู้พบของ | ส่งต่อข้อมูลสิ่งของที่พบได้สะดวก โดยไม่ต้องเปิดเผยข้อมูลส่วนตัวหรือรับภาระเก็บของไว้เอง | แจ้งพบของ ระบุสถานที่พบ แนบภาพถ่ายที่เหมาะสม และส่งมอบของตามกระบวนการ |
| เจ้าหน้าที่ศูนย์รับของหาย | บันทึก รับเข้า จ่ายออก ค้นหา และตรวจสอบสิ่งของได้อย่างเป็นระบบ | จัดการรายการสิ่งของ ตรวจสอบหลักฐาน อัปเดตสถานะ และติดตามของตกค้าง |
| ผู้ดูแลระบบ IT | ดูแลระบบให้เสถียรและควบคุมสิทธิ์เข้าถึงข้อมูลตามบทบาท | จัดการสิทธิ์ผู้ใช้ ตรวจสอบการเข้าถึง และดูแลมาตรการ Privacy/PDPA |
| ผู้บริหาร / ผู้กำหนดนโยบาย | ลดข้อร้องเรียนและกำหนดนโยบายจัดการสิ่งของตกค้างให้ตรวจสอบได้ | ดูรายงานภาพรวม กำหนดแนวทางจัดการของตกค้าง และติดตามความเสี่ยงระดับนโยบาย |

## 5. Success Criteria ระดับสูง

- [SC-01] ผู้ใช้สามารถแจ้งของหายหรือแจ้งพบของเข้าสู่ระบบส่วนกลางได้โดยมีข้อมูลเพียงพอต่อการค้นหาและตรวจสอบ
- [SC-02] ผู้ทำของหายสามารถค้นหารายการที่เกี่ยวข้องและส่งหลักฐานยืนยันความเป็นเจ้าของได้โดยไม่เปิดเผยข้อมูลส่วนตัวต่อสาธารณะ
- [SC-03] เจ้าหน้าที่สามารถบันทึก ค้นหา อัปเดตสถานะ และตรวจสอบประวัติการรับเข้า-จ่ายออกของสิ่งของได้
- [SC-04] ระบบมีแนวทางปกปิดข้อมูลส่วนบุคคลจากภาพถ่ายหรือคำบรรยาย และมีการจัดการสิทธิ์เข้าถึงตามบทบาท
- [SC-05] ระบบช่วยแจ้งเตือนหรือออกรายงานสิ่งของที่ไม่มีผู้มารับตามระยะเวลาที่นโยบายกำหนด
